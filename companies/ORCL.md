## Moat Assessment

- **Database Incumbency:** 40+ years of mission-critical Oracle DB deployments — nearly un-rippable
- **OCI AI Inflection:** Gen2 cloud with RDMA networking attracting AI training workloads (NVIDIA partnership)
- **SaaS Portfolio:** Fusion ERP, NetSuite SMB ERP, Cerner healthcare — high-switching-cost verticals
- **Multi-Cloud Strategy:** Azure Oracle DB, AWS Oracle DB, Google Cloud Oracle DB partnerships

## Risks

1. **Cloud Competition:** AWS/Azure/GCP are formidable; OCI is a distant #4
2. **Database Disruption:** PostgreSQL, MongoDB, cloud-native DBs chipping at Oracle DB share
3. **Cerner Integration:** $28B healthcare bet — slow growth, long implementation cycles
4. **AI CapEx:** OCI AI bookings need to convert to sustained revenue

## Catalysts

- OCI AI infrastructure — $10B+ capex, NVIDIA GPUs at scale
- Multi-cloud database deals expanding TAM
- Cerner EHR modernization bringing healthcare to the cloud
- Stargate AI project involvement (OpenAI / SoftBank JV)
