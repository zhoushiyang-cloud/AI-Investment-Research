ℹ️ 业务概览

  • Amazon.com, Inc. 通过三个主要分部运营：北美电商、国际电商和亚马逊网络服务（AWS）。

  • AWS 是占主导地位的云基础设施提供商，与MSFT（Azure）和GOOGL（GCP）竞争。它是主要的利润引擎，贡献了绝大部分营业利润。

  • 电商（北美+国际）仍是最大的收入贡献者，但利润率微薄。公司正大力投资同日达物流，以抵御WMT和TGT的市场份额竞争。

  • 关键增长驱动力：AWS AI服务（Bedrock、Trainium）、广告业务（高利润率、两位数增长）以及第三方卖家服务（FBA）。

  • 收入结构（2025财年）：总营收7169亿美元。虽然未提供分部数据，但历史趋势表明AWS约占收入的15-17%，却贡献超过60%的营业利润。

📊 财务分析

  • 营收：从5748亿美元（2023财年）→ 6380亿美元（2024财年）→ 7169亿美元（2025财年），同比增长12.4%。这明显快于2024财年11.0%的增速。

  • 利润率：毛利率提升至2025财年的21.4%（2024财年为20.7%）。营业利润率扩大至11.2%（2024财年为10.8%），得益于成本效率提升和更高利润率的AWS/AI业务占比增加。

  • 盈利能力：净利润在2025财年飙升至777亿美元（摊薄每股收益：7.17美元），高于2024财年的592亿美元（5.53美元）和2023财年的304亿美元（2.90美元）。这意味着净利润同比增长31%。

  • 现金流：2025财年经营现金流为1395亿美元，高于2024财年的1159亿美元。然而，资本支出（物业及设备购置）跃升至1318亿美元（2024财年为830亿美元），反映出激进的AI基础设施投入。自由现金流（经营现金流-资本支出）约为77亿美元，低于2024财年的约329亿美元。

  • 资产负债表：总资产8180亿美元，总负债4159亿美元。现金及等价物+短期投资 = 1230亿美元，长期债务为656亿美元。净现金头寸强劲，约为574亿美元，为投资和回购提供了充足的流动性。

    3. 2025财年资本支出激增至1318亿美元（同比增长59%）。如果对AI基础设施的大规模投资未能带来相应的收入/利润增长，资本回报率将下降，导致利润率压力和潜在减值。

  3. 监管与反垄断风险 #medium

    4. FTC诉讼和潜在的欧盟《数字市场法案》行动可能迫使亚马逊改变其市场平台做法，影响第三方卖家费用和广告收入。

  4. 内部人士减持信号 #medium

    5. 近期内部人士在239至266美元区间（高于当前233.66美元）的减持可能表明管理层认为该股短期内已充分估值，尽管这也可能是常规的投资组合多元化操作。

  5. 宏观经济放缓 #medium

    6. 经济衰退将压制可选消费支出（电商）和企业云预算（AWS），可能导致收入增长降至10%以下。
