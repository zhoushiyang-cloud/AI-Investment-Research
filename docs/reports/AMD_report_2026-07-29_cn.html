ℹ️ 业务概览

  • 公司： Advanced Micro Devices, Inc. (AMD) 是一家全球半导体领导者，总部位于加州圣克拉拉，拥有31,000名员工。其在GPU领域直接与NVDA竞争，在CPU领域与INTC竞争。

  • 业务分部： 公司运营两大主要分部：

  1. 计算与图形： x86微处理器（Ryzen, Threadripper）、芯片组和GPU（Radeon, Radeon Pro）。该分部面向消费级PC和专业图形市场。

  2. 企业、嵌入式和半定制： 服务器处理器（EPYC）、嵌入式解决方案以及游戏主机（索尼PlayStation、微软Xbox）的定制SoC。

  • 竞争地位： AMD在x86 CPU市场（仅次于INTC）和独立GPU市场（仅次于NVDA）均排名第二。其关键竞争优势是"Zen"架构和小芯片设计，这使其在数据中心CPU领域获得了显著市场份额。公司也是AI基础设施建设的重大受益者，为训练和推理提供GPU（Instinct MI系列）。

  • 收入驱动因素： 主要增长驱动力是数据中心分部（包含在上述两个分部中），由AI推动。半定制业务具有周期性，与游戏主机生命周期相关。

📊 财务分析

  • 收入趋势： 营收增长强劲：$22.68B (FY2023) → $25.79B (FY2024) → $34.64B (FY2025)。2025财年同比增长34%。

  • 利润率： 毛利率健康，为50.3%（TTM）。然而，营业利润率仅为11.7%（TTM），受高额研发费用（$8.09B，占营收23.4%）和销售管理费用（$4.14B，占营收12.0%）拖累。净利润率为13.4%（TTM）。

  • 现金流： 经营现金流强劲，为$7.71B（FY2025）。自由现金流为$6.74B（FY2025），按当前市值计算，自由现金流收益率仅为1.16%。资本支出可控，为$974M（FY2025），占营收的2.8%。

  • 资产负债表： 资产负债表稳健。总债务为$4.47B，但净债务为负（-$1.07B），意味着现金（$5.54B）超过债务。流动比率为2.72倍，速动比率为1.96倍。然而，商誉和无形资产高达$41.8B（占总资产的54%），这是收购赛灵思的遗留问题。

  • 关键担忧： 股权激励费用（SBC）为$1.64B（FY2025），占经营现金流的24%。这显著稀释了股东权益，是一项压低每股真实自由现金流的隐性成本。

  1. AI GPU市场份额流失 #critical

    2. AMD的MI300/MI400系列正在与NVDA占主导地位的CUDA生态系统竞争。如果AMD未能在超过$100B的数据中心GPU市场获得有意义的份额，营收增长将停滞。该股的估值完全依赖于这一叙事。

  2. 估值倍数压缩 #critical

    3. 在147.6倍市盈率下，该股定价完美。业绩指引低于预期10%，或投资者情绪从AI热潮中转变，都可能导致30-50%的回调。最近单日8.1%的下跌是一个警告信号。

  3. 客户集中度与周期性 #medium

    4. AMD的半定制业务（游戏主机）与游戏主机周期挂钩，该周期已成熟。PC市场或企业IT支出的低迷将损害计算与图形分部。

  4. 股权激励稀释 #medium

    5. 股权激励费用$1.64B（FY2025）占营收的4.7%。这是一项降低每股经济收益的真实成本。如果股权激励费用增速持续快于营收，将压低内在价值。

  5. 地缘政治/供应链 #low

    6. AMD依赖台积电进行先进芯片制造。台湾地区的任何动荡或对华AI芯片出口管制都可能实质性影响营收。

  2. 数据中心CPU市场份额增长 #medium-term

    3. AMD的EPYC Turin（Zen 5）处理器在服务器市场持续从INTC的Xeon手中夺取份额。任何重大新云部署的公告都将是一个积极催化剂。

  3. 利润率扩张 #medium-term

    4. 如果AMD能将营业利润率从当前的11.7%提升至20%以上（随着营收规模扩大和研发杠杆效应显现），该股将实现显著的每股收益增长。

  4. 回购公告 #near-term

    5. 凭借强劲的资产负债表（净现金头寸）和股价低迷，AMD可能宣布大规模股票回购计划，表明管理层信心。
