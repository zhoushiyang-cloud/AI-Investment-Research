📋 执行摘要

  • 微软在FY2025交出了亮眼成绩，总收入达 $281.7B（同比增长14.9%），营业收入达 $128.5B（同比增长17.5%），主要受Azure和AI服务持续强劲表现驱动。

  • 稀释后每股收益增长至 $13.64（高于FY2024的 $11.80），得益于强劲的运营杠杆和 $24.1B 的股票回购计划。

  • 自由现金流依然稳固，经营活动现金流为 $136.2B，资本支出 $64.6B 后自由现金流为 $71.6B，凸显了公司为AI基础设施投资提供资金的能力。

  • 资产负债表状况极佳，持有 $94.6B 现金及短期投资，长期债务为 $40.2B，提供了充足的战略灵活性。

  • 当前股价 $381.58 对应约28倍追踪市盈率，高于历史平均水平，但由加速增长、AI变现和强大的竞争护城河所支撑。

ℹ️ 业务概览

微软是一家全球科技领导者，业务涵盖三个主要板块：

  • 智能云（估计约占收入45%）：Azure、GitHub、SQL Server和企业服务。随着企业迁移工作负载并采用AI解决方案，Azure持续获得市场份额。

  • 生产力与业务流程（估计约占收入30%）：Office 365、LinkedIn、Dynamics 365。经常性订阅收入提供了高可见性和利润率。

  • 更多个人计算（估计约占收入25%）：Windows、Xbox、Surface和搜索广告。该板块更具周期性，但受益于Windows 11升级周期和游戏业务。

竞争地位：微软在云基础设施领域排名第二，落后于AMZN AWS，但在企业软件（Office、Teams、Dynamics）领域是明确的领导者。其与NVDA的合作以及对OpenAI的投资，使其成为企业采用AI的主要平台。公司受益于高转换成本、庞大的安装基础和多元化的收入模式。

📊 财务分析

收入趋势：FY2025总收入为 $281.7B，高于FY2024的 $245.1B（增长14.9%）和FY2023的 $211.9B（两年增长33%）。随着AI工作负载推动Azure消费，增长正在加速。

利润率：由于AI基础设施成本上升，毛利率从FY2024的69.8%降至FY2025的68.8%，但营业利润率从44.6%扩大至45.6%，因为销售、一般及行政费用和研发支出增速低于收入。研发支出为 $32.5B（占收入的11.5%），反映了对AI的大力投资。

现金流：FY2025经营活动现金流为 $136.2B，高于FY2024的 $118.5B。资本支出激增至 $64.6B（FY2024为 $44.5B），用于建设AI数据中心，导致自由现金流为 $71.6B。公司通过回购（$24.1B）和股息（$24.1B）向股东返还了 $42.5B。

资产负债表：总资产 $619.0B，现金/短期投资 $94.6B。总债务为 $40.2B（长期）加上 $4.6B 的资本租赁。净现金头寸约 $50B，为并购或进一步回购提供了强大火力。

ℹ️ 估值评估

当前倍数（基于FY2025数据）：

  • 市盈率（追踪）：$381.58 / $13.64 = 28.0倍

  • 企业价值/息税折旧摊销前利润：企业价值 = $381.58 * 74.65亿股 = $2.85T - $94.6B 现金 + $44.8B 债务 = 约 $2.80T；息税折旧摊销前利润 = $128.5B + $28.0B 折旧摊销 = $156.5B → 17.9倍

  • 市销率：$2.85T / $281.7B = 10.1倍

历史背景：微软的5年平均市盈率约为32倍。当前28倍相对于该平均水平存在折价，可能源于对资本支出上升和宏观不确定性的担忧。与大型科技同行相比：NVDA交易约45倍，AVGO约30倍，AAPL约30倍。微软相对于自身历史水平的溢价是合理的，原因如下：

  • AI收入加速（Azure AI收入同比增长超过100%）

  • 尽管投资巨大，营业利润率仍在扩大

  • 经常性收入基础（超过70%的收入来自订阅/年金）

结论：以28倍市盈率计算，MSFT相对于其增长轨迹估值合理。如果AI变现超出预期，30-32倍的市盈率是可以实现的。

  1. AI资本支出过度投资 #critical

    2. FY2025资本支出激增至 $64.6B（占收入的23%）。如果AI需求增长放缓，或者GOOGL和AMZN等竞争对手侵蚀Azure的市场份额，这些投资可能无法产生足够的回报，从而给利润率和自由现金流带来压力。

  2. 监管审查 #medium

    3. 微软在欧盟和美国面临关于其云捆绑销售做法以及与OpenAI合作关系的持续反垄断调查。强制分拆或对AI合作伙伴关系的限制可能会削弱增长。

  3. Azure增长减速 #medium

    4. Azure收入增长虽然强劲，但随着基数效应增大和企业优化云支出，可能会减速。FY2025 Azure加速增长，但任何放缓都将压缩估值倍数。

  4. 网络安全与数据隐私 #low

    5. 作为关键基础设施提供商，任何重大安全漏洞（如2024年影响Windows的CrowdStrike事件）都可能导致客户流失和声誉损害。

  5. 汇率逆风 #low

    6. 由于约50%的收入来自美国以外，美元走强（如近期价格走势所示）可能使报告收入和每股收益减少1-3%。

    4. Windows 10于2025年10月终止支持将迫使企业升级，从而在FY2026提振更多个人计算板块的收入和利润率。
