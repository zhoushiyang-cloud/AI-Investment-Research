  • 微软（MSFT）在2025财年表现卓越，营收同比增长14.9%至2817亿美元，主要受云计算和AI基础设施货币化驱动。营业利润增长17.4%至1285亿美元。

ℹ️ 业务概览

  • 公司： 微软是生产力软件（Office、Teams）、云计算（Azure）以及日益增长的AI基础设施（Copilot、OpenAI合作伙伴关系）领域的全球领导者。

  • 竞争地位： 在企业SaaS领域（Office 365、Dynamics 365）占据主导地位，是仅次于AMZN AWS的第二大云服务提供商（Azure）。与OpenAI的早期深度合作使其在企业AI领域拥有先发优势。

  • 主要业务板块（2025财年营收结构 — 估算）：

  • 智能云（Azure、服务器产品）： 约占营收的45%。Azure按固定汇率计算同比增长约22%，由AI工作负载驱动。

  • 生产力与业务流程（Office、LinkedIn、Dynamics）： 约占营收的32%。Office 365商业席位增长，Copilot推动ARPU扩张。

  • 更多个人计算（Windows、Xbox、Surface、搜索）： 约占营收的23%。Windows OEM和搜索（必应）受益于AI集成。

📊 财务分析

  • 营收： 2025财年营收为2817亿美元，较2024财年的2451亿美元增长14.9%。相较于2024财年较2023财年15.7%的增速，这是明显的加速增长。

  • 利润率： 毛利率为68.8%（1939亿美元毛利润 / 2817亿美元营收），较2024财年的69.8%略有下降，原因是AI基础设施成本上升。营业利润率为45.6%（1285亿美元 / 2817亿美元），高于2024财年的44.6%，显示出经营杠杆效应。

  • 现金流： 经营现金流高达1362亿美元，高于2024财年的1185亿美元。自由现金流（经营现金流 — 资本支出）为717亿美元（1362亿美元 — 646亿美元），由于资本支出加速，低于2024财年的738亿美元。

  • 资产负债表： 总资产为6190亿美元，总负债为2755亿美元。净现金（现金及短期投资946亿美元减去总债务431亿美元）为514亿美元，提供了显著的财务灵活性。

  • 股东回报： 2025财年回购了184亿美元股票，并支付了241亿美元股息。稀释后股数从74.69亿股降至74.65亿股。

ℹ️ 估值评估

  • 当前市盈率（TTM）： 股价381.58美元 / 稀释后每股收益13.64美元 = 约28.0倍。相对于标普500指数（约22倍）存在溢价，但微软的卓越增长和利润率证明了这一溢价的合理性。

  • EV/EBITDA： 企业价值（市值约2.85万亿美元 + 净债务）/ EBITDA（1285亿美元营业利润 + 280亿美元折旧摊销 = 1565亿美元）= 约18.2倍。对于一家拥有持久竞争优势的科技巨头而言，这是合理的。

  • 历史背景： 过去5年，微软的市盈率区间为25-35倍。当前28倍处于该区间的中段，尚未充分反映AI收入周期的全部潜力。

  • 合理性论证： 加速的营收增长（2025财年14.9%）、扩张的营业利润率（45.6%）以及企业AI领域的巨大潜在市场证明了这一溢价的合理性。鉴于现金流生成能力，当前估值并未过度拉伸。

  1. AI资本支出压力与货币化滞后 #critical

    2. 2025财年资本支出激增至646亿美元（占营收的23%），较2024财年增长45%。如果AI工作负载（Copilot、Azure AI）未能在未来2-3年内产生相应的投入资本回报率（ROIC），利润率和自由现金流将受到压缩，导致估值倍数收缩。

  2. 云与AI领域的竞争 #high

    3. AMZN AWS和GOOGL GCP正在积极投资于自身的AI模型和基础设施。NVDA是主导性GPU供应商，AVGO在定制AI芯片领域（如谷歌的TPU）正在获得市场份额。微软对OpenAI前沿模型的依赖是单点故障风险。

  3. 监管审查 #medium

    4. 美国联邦贸易委员会（FTC）和欧盟日益关注大型科技公司的AI合作伙伴关系。微软对OpenAI的130亿美元投资正在接受审查。强制剥离或对其整合OpenAI模型的限制可能会对AI增长叙事产生实质性影响。

  4. PC市场成熟 #low

    5. “更多个人计算”板块（占营收的23%）具有周期性。企业PC更新周期放缓或Windows OEM市场下滑可能对整体增长构成阻力。
